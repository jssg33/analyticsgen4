Database Tables

The EF tables discovered on each API by the host-side table audit (SqlAzureTableAudit, written to the DatabaseTable table). Pick a source to read its /api/databasetables. Discovery runs on the host side; here you record each table's Schema Area (what it's used for). Fields (or click a table) opens its columns from /api/databasefields, where you can add, edit and delete them or run field discovery. See Report 02 for the breakdown.

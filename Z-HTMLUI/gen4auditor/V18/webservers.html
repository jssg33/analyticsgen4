Web Servers

Every web server you audit, whether it runs on its own or as a member of a web farm (farm membership is set on the Web Farms page). Role comes from the two proxy flags: Backend web servers sit behind a proxy (Is Proxy off, Is Proxy Slave on); Proxy servers have Is Proxy on; Role not set means neither is ticked yet. Findings checks each server against the policy in config.js. Hover to see the problems, or click to open them in Infra Audit.

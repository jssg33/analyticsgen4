Back-end Interfaces

The services and interfaces registered behind each API, one row per interface method. They're imported per host when the host is audited (Walk Swagger & audit host reads the API's SystemConsole), or with Import from host. Associate endpoints then ties each method to the endpoint that serves it. CockyAuditor records what's exposed — it never calls these methods.

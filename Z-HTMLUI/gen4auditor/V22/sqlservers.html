SQL Catalog

The databases you catalog (AuditSqlServers), their tables and columns, and where PHI and PII live. Tables opens a database's tables; Import from SQL fills in tables and columns from the database itself. Findings flag unencrypted PHI / PII columns, tables whose PHI / PII flags don't match their columns, missing primary keys and owners, and versions past end of support.
Import from SQL
  1. Run this query in the database (SQL Server 2016+ / Azure SQL). It also reads table size, statistics date, row-level security and dynamic data masking. Other database types: paste any result with the same column names.
  2. Copy the whole result with its headers (SSMS: right-click the grid → Copy with Headers), or paste CSV or JSON.
  3. Preview shows what will be added. Existing tables and columns are never changed.

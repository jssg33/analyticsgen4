Poller

Pings the IP address behind each chosen endpoint's URL, never the API itself: the host name is resolved to an IP (DNS over HTTPS), then the poller times a bare connection to https://<ip>:<port>/ with no API path, no credentials and nothing read back. Any answer, even a refused connection or a certificate error, means the host is up; only no reply within the timeout counts as down. Endpoints that share an IP and port are pinged once.
